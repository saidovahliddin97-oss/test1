# Правила проекта

## Git
- Все изменения после коммита и пуша в рабочую ветку автоматически сливать в `main`
  (fast-forward или merge) и пушить `main` — без отдельного запроса и без PR.

## Скиллы
Скиллы проекта лежат в `.claude/skills/`:
- `/grill-me` (+ `grilling`) — интервью для стресс-теста плана (mattpocock/skills, MIT)
- `frontend-design` — гайд по выразительному визуальному дизайну UI (anthropics/skills, Apache-2.0)
